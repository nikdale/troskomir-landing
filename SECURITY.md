# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.
Use GitHub's private security advisory flow for this repository, or contact
the maintainer at the private address listed in the repository owner profile.
Include the affected version, reproduction steps, and any suggested
mitigation. Do not include real user data or credentials.

Reports are acknowledged within seven days and triaged according to impact.
Please allow time for a fix and coordinated disclosure before publishing
details.
